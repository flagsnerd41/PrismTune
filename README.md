# PrismTune2

### Your music. Your atmosphere.

**A personal Metrolist fork focused on a softer, more atmospheric listening experience.**

Exploring gentle motion, glow effects, floating elements, and a more expressive player UI while keeping the solid YouTube Music + local playback foundation.

## About

PrismTune2 is an independent Android music-player fork based on [Metrolist](https://github.com/MetrolistGroup/Metrolist).

It keeps the core features people love (YouTube Music streaming, offline downloads, synced lyrics, library management, etc.) while developing a distinct visual identity around soft atmosphere, subtle motion, and a more polished player experience.

> [!NOTE]
> This is a personal / experimental fork. It is **not** affiliated with the Metrolist project or its maintainers.

---

## Current direction

- Soft atmospheric effects (leaves, glow / fairy lights, gentle wind)
- Rounder UI elements and floating navigation
- Smoother player transitions and progress feel
- Cozy, low-clutter visual language

## Getting a build

Builds are published as GitHub Actions artifacts when the workflow succeeds.

1. Open the [Actions](https://github.com/flagsnerd41/PrismTune2/actions) tab
2. Pick a successful **Build** run
3. Download the APK artifact you want
4. Install on your device

> [!IMPORTANT]
> Different signing keys or variants may require uninstalling the previous build first (this will clear local data).
