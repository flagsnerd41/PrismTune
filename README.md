# PrismTune

### Clean YouTube Music client for Android

A sharp, modern fork focused on performance, clarity, and zero clutter.

</div>

---

## Features

- Stream any song or video from YouTube Music
- Background playback + offline downloads
- Live synced lyrics + AI translation
- Equalizer, tempo & pitch control, crossfade
- Audio normalization & skip silence
- Local playlists + YouTube Music library sync
- Listen together, Last.fm scrobbling
- Material 3 with dynamic color
- FOSS / GMS / IzzyOnDroid builds
