# PrismTune

**Your music. Your atmosphere.**

A personal Metrolist fork focused on a softer, more atmospheric listening experience — with gentle motion, glow effects, floating elements, and a more expressive player UI.

### About

PrismTune is an independent Android music player based on [Metrolist](https://github.com/MetrolistGroup/Metrolist). It keeps the solid YouTube Music + local playback foundation while developing a distinct cozy visual identity.

> This is a personal experimental fork and is **not** affiliated with Metrolist.

### Current direction

- Soft atmospheric effects (leaves, glow / fairy lights, gentle wind)
- Rounder UI elements and floating navigation
- Smoother player transitions
- Cozy, low-clutter look

### Features

YouTube Music streaming · Offline downloads · Synced lyrics · Library management · Local playlists · Last.fm · Discord Rich Presence · Equalizer · Crossfade · and more from Metrolist.

### Getting a build

1. Go to [Actions](https://github.com/flagsnerd41/PrismTune2/actions)
2. Download the APK from a successful build
3. Install on your device
