## 🌈 About PrismTune

PrismTune is an independent Android music-player fork focused on a polished, atmospheric interface with smooth transitions, subtle visual depth, and a listening experience that feels refined rather than cluttered.

It is based on [ArchiveTune](https://github.com/rukamori/ArchiveTune), an open-source music player built with Kotlin and Jetpack Compose. PrismTune keeps developing from that foundation while exploring its own visual identity and improvements.

> [!NOTE]
> PrismTune is a work in progress. Some features and interface elements are inherited from ArchiveTune, and the design is still evolving.

## ✨ Current direction

- **Refined visuals** — subtle depth and a softer, atmospheric player experience.
- **Smoother playback progress** — animated progress updates with direct interaction while seeking.
- **Subtle motion** — polished title transitions and gentle visual animation in the expanded player.
- **A familiar music-player foundation** — build on ArchiveTune's existing playback and discovery features while PrismTune develops.

## 🎧 Features from the ArchiveTune foundation

The underlying project includes features such as:

- YouTube Music account integration and playlist access
- Background and ad-free playback
- Local music playback
- Synced lyrics and lyric translation
- Playback speed, pitch, tempo, and loudness controls
- Crossfade, equalizer integration, and spatial-audio integration
- Listening statistics, Last.fm scrobbling, and ListenBrainz sync
- Dynamic colors, player styles, gestures, and interface customization

Availability can depend on the upstream implementation, external services, account configuration, and region. PrismTune is an unofficial fork and is not affiliated with Google or YouTube.

## 📦 Get a build

PrismTune builds are published as GitHub Actions artifacts when the workflow completes successfully.

1. Open [GitHub Actions](https://github.com/flagsnerd41/PrismTune/actions).
2. Select a successful **Build APKs** workflow run.
3. Download the artifact for the build you want, such as the mobile universal debug or release build.
4. Extract the downloaded artifact and install the APK on your Android device.

> [!IMPORTANT]
> Builds from different variants or signing keys may not install as updates over one another. If Android asks you to uninstall an existing version, pause before doing so if you need to preserve the app's local data.
